# Markify 🚀

> **Zero-Install, Zero-Build Modern Documentation Engine**

Markify is a lightweight, client-side engine that instantly transforms your Markdown files into a modern, beautifully styled documentation website—completely free of Node.js, `npm install`, or complex build steps.

---

## Key Features ✨

- ⚡ **Zero Setup:** Works instantly out of the box with just a single `index.html` file.
- 🎨 **Glassmorphism Design:** Clean, modern, and aesthetic glass-UI layout.
- 🌙 **Light & Dark Mode:** Built-in automatic dynamic theme switching.
- 🔍 **Instant Search:** Fast client-side searching powered by FlexSearch with `Ctrl + K` shortcut support.
- 📌 **Floating ToC:** Automatically generates an on-page Table of Contents from your headings.
- 💻 **Code Copy & Highlight:** Features one-click code copying and syntax highlighting via Prism.js.

---

## Quick Start 🛠️

Simply create an `index.html`, a `_sidebar.md`, and a `README.md` file in your project directory, then open it using any local web server to get started immediately.

```
.
├── index.html
├── _sidebar.md
└── README.md
```
